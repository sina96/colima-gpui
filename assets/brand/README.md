# Brand assets

| File | What it is | Used by |
|---|---|---|
| `ColimaGPUI.icon` | The app icon: an [Icon Composer](https://developer.apple.com/icon-composer/) document with three layers (VM, runtime, containers) on the Colima dark background. | `just icons` builds `packaging/AppIcon.icns` and `packaging/Assets.car` from it. |
| `icon.png` | 512 px render of the app icon. Generated by `just icons`. | The README. |
| `logo.svg` | The full-color mark on a transparent background: three stacked blocks forming a "C". | The source for the layers in `ColimaGPUI.icon`. |
| `tray.svg` | The menu bar glyph: the same blocks as solid silhouettes with gaps, one color. macOS uses only its alpha and tints it for light and dark menu bars. | Compiled into the app (`src/tray/icon.rs`). |

The blocks stand for the layers the app manages: the VM (grey), the container runtime (white) and the containers (green).

To change the icon, edit `ColimaGPUI.icon` in Icon Composer, run `just icons`, and commit the regenerated files.
