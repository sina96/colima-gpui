# Get help with Colima GPUI

Colima GPUI is an independent project. It isn't part of Colima, so don't report Colima GPUI problems to the Colima maintainers.

## Find an answer

- Read the [README](README.md).
- Search the [open and closed issues](https://github.com/sina96/colima-gpui/issues?q=is%3Aissue).

## Ask for help

If the README doesn't answer your question, open a [question](https://github.com/sina96/colima-gpui/issues/new?template=question.yml). Say what you tried, what you expected, and your Colima GPUI version.

## Report a bug or suggest a feature

- **Bug report:** something doesn't work as described. Open a [bug report](https://github.com/sina96/colima-gpui/issues/new?template=bug_report.yml).
- **Feature request:** an idea for something new. Open a [feature request](https://github.com/sina96/colima-gpui/issues/new?template=feature_request.yml).
- **A problem in Colima itself** (a VM that won't start from the terminal either, for example): report it to [Colima](https://github.com/abiosoft/colima/issues).

This is a volunteer project, so there's no fixed response time.

## Report a security problem

Don't open a public issue. Follow [SECURITY.md](SECURITY.md).
